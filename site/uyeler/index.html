Kendini ekle

Liste GitHub'da tutuluyor. Kendi dosyanı bir pull request ile eklersin, onaylanınca profilin burada görünür. Kimse seni senin yerine ekleyemez: otomatik kontrol, PR'ı açan kişinin sadece kendi dosyasına dokunmasına izin verir.

1. Dosyanı oluştur

Aşağıya GitHub kullanıcı adını yaz, şablon hazır olarak GitHub'da açılsın.

2. Bilgilerini doldur

Paylaşmak istemediğin isteğe bağlı alanları sil, ardından "Propose changes" ile PR aç.

3. Kontrol ve onay

Otomatik kontrol geçer, bir yönetici onaylar, profilin listede görünür.

GitHub'da dosyamı oluştur ↗
Dosya adı: members/<kullanici-adi>.json
